# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Readers tracking public Microsoft Copilot and agent announcements, roadmap
features, and Ignite updates.

## Product Purpose

Provide a searchable, curated, publicly accessible snapshot with direct
citations so readers can find an update and inspect its source.

## Capabilities and Constraints

- Static HTML, CSS, and JavaScript hosted on GitHub Pages.
- Search, product filters, source filters, sorting, and direct source URLs.
- A dedicated Ignite 2026 view with individual verified announcements.
- Reviewed snapshots refreshed on request, not a live synchronization service.
- Publish public-source information only. No private data, internal annotations,
  people, tenant identifiers, credentials, or restricted content.
- Retain source provenance and clearly label independent Message Center mirrors.
- No analytics, authentication, remote fonts, or runtime dependencies.

## Brand Commitments

The approved reference establishes a compact white-and-blue application shell,
left navigation, rounded filter panels, product pills, and a pink Ignite section.
Adapt its visual language without copying private assets, content, or menus.

## Evidence on Hand

`data.json` is the reviewed public snapshot. The existing public feed and its
source URLs must remain unchanged during visual updates. Private source exports,
reference screenshots, and verification evidence stay outside this repository.

## Product Principles

- Public facts and traceable sources before visual presentation.
- Preserve existing information and working search/filter behavior.
- Do not imply that this independent snapshot is an official Microsoft service.
- Keep keyboard navigation and small-screen use practical.
